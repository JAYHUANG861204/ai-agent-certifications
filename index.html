AI Agent 證照地圖

整理目前(2026 年)主要廠商推出的 AI Agent / Agentic AI 相關證照，依基礎、助理、專業、領導四個等級分類，方便評估要考哪一張。

最後更新 — 共收錄 0 張證照 更新方式：共編（PR 審核）
篩選等級

關於登入：右上角可用 Google 帳號登入，登入後才能瀏覽內容。登入後會出現「同步資料到資料庫」按鈕，可以把 data/certs.json 目前的內容整批寫入 Firestore；網頁預設會優先顯示 Firestore 資料庫裡的內容，資料庫是空的時候才會退回讀取靜態檔案。

關於共編：證照資料的「原始檔」存放在 data/certs.json（分類定義在 data/categories.json），與頁面邏輯分開管理。歡迎直接開 Pull Request 更新內容，格式錯誤會被 scripts/validate.mjs 自動擋下，詳見 CONTRIBUTING.md。PR 合併後還需要有人登入按一次同步，資料庫才會更新。

資料來源：各證照卡片右下角皆附原始參考連結；價格、時長、通過門檻等細節可能隨廠商調整，正式報名前請以官方頁面為準。

關於「台灣考試」欄位：AWS、Microsoft、Oracle 系列透過 Pearson VUE 排考，台北有實體考場（也可選線上 OnVUE 監考）；Google Cloud、Salesforce、NVIDIA、UiPath、GSDC、ADaSci 皆為純線上監考，台灣不在任何已知的地區限制名單內，僅需準備可用網路攝影機的穩定網路環境與英文姓名一致的證件。
